Phase 22.13: Render controls by section bands (Header / Detail / Footer) in published forms and popup. Fixes overlap between header controls and detail controls.

CONTEXT: Each control in the controls table has a `section` field with value 'header' | 'detail' | 'footer'. Studio Design View already renders 3 separate bands and filters controls by section (lines ~2156, ~2181, ~2206 in src/app/(app)/studio/[slug]/page.tsx). But /app/[slug]/page.tsx and PopupFormOverlay.tsx render ALL controls in one absolute-positioned container without filtering, causing header controls to overlap detail controls.

This commit touches exactly two files:
- src/app/app/[slug]/page.tsx (two render blocks: modal variant + normal page)
- src/components/PopupFormOverlay.tsx (popup render block)

Do NOT touch any other file (NOT Studio, NOT NexBaseControl).

==================================================================
SHARED PATTERN — what to do at every render site
==================================================================

Each existing `controls.map(...)` block currently looks like:

  <div style={{ position: 'relative', minHeight: 400 }}>
    {controls.map((ctrl) => (
      <div key={ctrl.id} style={{ position: 'absolute', left: ctrl.x, top: ctrl.y }}>
        <NexBaseControl ctrl={ctrl} ... />
      </div>
    ))}
    {controls.length === 0 && (<div>No controls on this page yet.</div>)}
  </div>

Replace each such block with THREE stacked band divs:

  <div>
    {/* Header band — 60px */}
    <div style={{ position: 'relative', height: 60, background: '#f8fafc', borderBottom: '1px solid #e5e7eb' }}>
      {controls.filter(c => c.section === 'header').map((ctrl) => (
        <div key={ctrl.id} style={{ position: 'absolute', left: ctrl.x, top: ctrl.y }}>
          <NexBaseControl ctrl={ctrl} ... />
        </div>
      ))}
    </div>

    {/* Detail band — flex grows */}
    <div style={{ position: 'relative', minHeight: 400, background: '#ffffff' }}>
      {controls.filter(c => c.section === 'detail').map((ctrl) => (
        <div key={ctrl.id} style={{ position: 'absolute', left: ctrl.x, top: ctrl.y }}>
          <NexBaseControl ctrl={ctrl} ... />
        </div>
      ))}
      {controls.length === 0 && (
        <div style={{ display: 'flex', alignItems: 'center', justifyContent: 'center', height: 400, color: '#9ca3af', fontSize: 14 }}>
          No controls on this page yet.
        </div>
      )}
    </div>

    {/* Footer band — 60px */}
    <div style={{ position: 'relative', height: 60, background: '#f8fafc', borderTop: '1px solid #e5e7eb' }}>
      {controls.filter(c => c.section === 'footer').map((ctrl) => (
        <div key={ctrl.id} style={{ position: 'absolute', left: ctrl.x, top: ctrl.y }}>
          <NexBaseControl ctrl={ctrl} ... />
        </div>
      ))}
    </div>
  </div>

Important details:
- IMPORTANT: include controls where `section` is null/undefined IN THE DETAIL band as a fallback. Replace the detail filter with:
    .filter(c => !c.section || c.section === 'detail')
  This protects existing controls that were created before sections existed.
- Keep the SAME NexBaseControl props that the existing block uses (formData, setFormData, handleButtonClick, visibleModal, setVisibleModal, etc.). Match exactly what's already there site-by-site.
- The "No controls on this page yet." empty state goes ONLY in the detail band.
- Do NOT change the OUTER wrapper div around the bands (the white card with borderRadius/padding/boxShadow). That stays unchanged. The 3 band divs go INSIDE that wrapper, replacing the current single map.
