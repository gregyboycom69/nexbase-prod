=== FIX 1 - AUTO-SAVE DEBOUNCE TOO SHORT ===

The auto-save fires every 1 second which interrupts typing.
Increase debounce to 3 seconds so user can type without interruption.

Find the debounce/setTimeout for auto-save and change:
setTimeout(..., 1000) → setTimeout(..., 3000)

Also: auto-save must NOT trigger while user is actively typing in:
- Property sheet inputs
- Caption inputs
- Any text input

Only auto-save when:
- Control is MOVED (mouseup after drag)
- Control is RESIZED (mouseup after resize)
- Control is ADDED (new control drawn)
- Control is DELETED
- Save Form button clicked (immediate save)

Do NOT auto-save on every keystroke in property inputs.
Property changes should only save when:
- Input loses focus (onBlur)
- User presses Enter
- Save Form button clicked
