When user clicks workspace card from dashboard, they go to 
/workspace/ggg which shows "Design a Table", "Create a Query", 
"Design a Form", "View Published App" cards. This is 
UNNECESSARY because the studio sidebar already has all this.

Make /workspace/[slug] automatically redirect to /studio/[slug].

FILE: src/app/(app)/workspace/[slug]/page.tsx

import { redirect } from 'next/navigation'

export default async function WorkspaceRedirect({

  params: Promise<{ slug: string }>

This makes /workspace/ggg automatically go to /studio/ggg.

PROBLEM:
When studio loads with no active page, it shows a "Welcome to ggg" 
screen with three big "Create a Table / Form / Query" buttons. 

This is REDUNDANT because the sidebar already has + buttons next 
to TABLES, FORMS, QUERIES, MACROS sections.

SOLUTION:
Remove the welcome screen. Replace with helpful empty state OR 
auto-select first table/form if any exist.

FILE: src/app/(app)/studio/[slug]/page.tsx

Find the section that renders when activePage is null/undefined.
Currently looks like:

{!activePage && (
  <div>
    <h1>Welcome to {workspace.name}</h1>
    <p>Get started:</p>
    <button>Create a Table</button>
    <button>Create a Form</button>
    <button>Create a Query</button>
  </div>

REPLACE with logic that auto-selects first item:

FIX 19.12.3 - REMOVE OR REDIRECT /studio/[slug]/tables
═══════════════════════════════════════════════════════════════════

PROBLEM:
The old dark-themed /studio/[slug]/tables page still exists.
Now that the inline table designer works in /studio/[slug],
this old page is REDUNDANT and uses the wrong dark theme.

SOLUTION:
Convert /studio/[slug]/tables to redirect to /studio/[slug] 
with the table active.

FILE: src/app/(app)/studio/[slug]/tables/page.tsx

REPLACE entire file with a simple redirect:

import { redirect } from 'next/navigation'

interface PageProps {
  params: Promise<{ slug: string }>
  searchParams: Promise<{ table?: string }>
}

export default async function TablesRedirect({
  params,
  searchParams,
}: PageProps) {
  const { slug } = await params
  const { table } = await searchParams
  
  if (table) {
    redirect(`/studio/${slug}?activeTable=${table}`)
  }
  redirect(`/studio/${slug}`)
}

This way any old links to /tables still work but land in the 
NEW studio with the requested table active.

FIX 19.12.4 - HANDLE activeTable QUERY PARAM IN STUDIO
═══════════════════════════════════════════════════════════════════

If users come from the redirect with ?activeTable=xxx, the studio 
should auto-open that table.

FILE: src/app/(app)/studio/[slug]/page.tsx

ADD at the start of the component, after loading tables:

import { useSearchParams } from 'next/navigation'

const searchParams = useSearchParams()
const queryActiveTable = searchParams.get('activeTable')

ADD effect to handle initial query param:

useEffect(() => {
  if (!queryActiveTable || !tables.length) return
  
  const targetTable = tables.find(t => t.id === queryActiveTable)
  if (targetTable) {
    setActivePage({
      id: targetTable.id,
      type: 'table',
      name: targetTable.name,
    })
  }
}, [queryActiveTable, tables])
