Section "Appearance":
  Back Color: [colored swatch] + hex input ← ctrl.props.bg
  Text Color: [colored swatch] + hex input ← ctrl.props.color
  Border Radius: number input ← ctrl.props.radius
  Visible: Yes/No select

  Font Size: number ← ctrl.props.fontSize
  Bold: Yes/No select ← ctrl.props.bold

  Caption: text input ← ctrl.props.caption

    - onChange: update ctrl.props.controlSource, save to Supabase on blur

  Default Value: text input
  Validation Rule: text input
  Validation Text: text input

  Locked: Yes/No select

=== SAVE BEHAVIOR ===

Auto-save triggers ONLY on:
- Control mouseup (after move or resize)
- Control added to canvas
- Control deleted

Auto-save does NOT trigger on:
- Typing in property sheet inputs
- Changing dropdowns in property sheet

Property sheet changes:
- onChange: update local React state immediately (instant preview)
- onBlur: save that control to Supabase
- Select onChange: save immediately (selects don't have blur issue)

Manual save: Ctrl+S or [Save] button
- Saves all controls
- Shows "Saved ✓" in green for 2 seconds

Every color must work in light AND dark mode.

Text colors: var(--color-text-primary), var(--color-text-secondary), var(--color-text-tertiary)
