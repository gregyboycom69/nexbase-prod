Add detailed MS Access style properties to EVERY control type.
Every control must have Format tab, Data tab, Event tab, Other tab.
The Data tab has Control Source dropdown showing fields from the bound table.

=== PROPERTY SHEET TABS FOR ALL CONTROLS ===

Every control when selected shows Property Sheet with 5 tabs:
Format | Data | Event | Other | All

The tabs work exactly like MS Access.
Small compact rows, two columns: property name | value input.

=== HOW TO BUILD THE PROPERTY SHEET COMPONENT ===

Create src/components/studio/PropertySheet.tsx

This component receives:
- selectedControl: the selected control object (or null for form properties)
- formRecordSource: the table/query the form is bound to
- workspaceTables: array of all tables in this workspace
- workspaceQueries: array of all queries in this workspace  
- workspaceForms: array of all forms/pages in this workspace
- workspaceMacros: array of all macros in this workspace
- onUpdateControl: function to update control properties
- onUpdateForm: function to update form/page properties

State inside PropertySheet:
- activeTab: 'format' | 'data' | 'event' | 'other' | 'all'

The component renders:
1. Header: "Property Sheet" title + "Selection type: TextBox" (or Form)
2. Control name dropdown at top (like Access shows the control name in a box)
3. Tab buttons: Format | Data | Event | Other | All
4. Property rows for the active tab

Each property row:
<div style display grid gridTemplateColumns 140px 1fr>
  <span style fontSize 11 color gray>{propertyName}</span>
  <input or select or colorpicker for the value>
</div>

For DROPDOWN properties (like Control Source):
Show a select element with all relevant options.
When Control Source is shown, populate with fields from formRecordSource table.

For COLOR properties:
Show a small colored square + text input for hex value.
Clicking square opens a simple color palette.

For YES/NO properties:
Show a select with Yes and No options.

For MACRO event properties:
Show a select with all workspace macro names + (None) option.

=== IMPORTANT IMPLEMENTATION NOTE ===

The Control Source dropdown in the Data tab is the KEY feature.

To populate it:
1. Get the form's recordSource (from page.recordSource in Supabase)
2. Fetch the workspace_tables entry for that table
3. Get the fields array from workspace_tables.fields JSONB
4. Show each field.name in the Control Source dropdown

If the form has no Record Source set:
- Control Source dropdown shows only: "(not bound - set Record Source on form first)"
- Show a hint message in blue: "Go to the canvas (deselect all) then set Record Source in Data tab"
