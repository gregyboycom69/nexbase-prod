=== HOW MS ACCESS WORKS (what we are building) ===

When you open a database in MS Access:
1. Left panel shows ALL objects: Tables, Queries, Forms, Reports, Macros
2. Main area is blank until you open an object
3. Double-click a Table → opens in datasheet view (spreadsheet)
4. Double-click a Form → opens in form view (shows the form)
5. Right-click → Design View → opens the designer for that object
6. You can have MANY forms open at once as tabs
7. Each form has its own designer with its own controls

THIS is what we need to build.

=== SUPABASE OPERATIONS ===

Load studio:
1. GET workspace from workspaces table by slug
2. GET all workspace_tables for this workspace
3. GET all workspace_queries for this workspace
4. GET all pages for this workspace (forms)
5. Populate navigation pane with all of these

Open a form (double-click from nav pane):
1. GET all controls for that page from controls table
2. Show form in design view or form view

Save a control:
UPSERT into controls table:
{ id, page_id, type, x, y, w, h, props: {...all properties}, macro_steps: [] }

Open a table (double-click from nav pane):
1. GET table definition from workspace_tables
2. GET records from app_data where workspace_id and table_name match
3. Show in datasheet view

Save a table definition:
UPSERT workspace_tables SET fields = [...] WHERE id = tableId

Store macros in:
CREATE TABLE IF NOT EXISTS workspace_macros (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id UUID REFERENCES workspaces(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  steps JSONB DEFAULT '[]',
  created_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE workspace_macros ENABLE ROW LEVEL SECURITY;
CREATE POLICY owner_macros ON workspace_macros FOR ALL USING (
  workspace_id IN (SELECT id FROM workspaces WHERE owner_id = auth.uid())
);

CREATE TABLE IF NOT EXISTS workspace_tables (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id UUID REFERENCES workspaces(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  slug TEXT NOT NULL,
  fields JSONB DEFAULT '[]',
  created_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE workspace_tables ENABLE ROW LEVEL SECURITY;
CREATE POLICY IF NOT EXISTS owner_wt ON workspace_tables FOR ALL USING (
  workspace_id IN (SELECT id FROM workspaces WHERE owner_id = auth.uid())
);

CREATE TABLE IF NOT EXISTS workspace_queries (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id UUID REFERENCES workspaces(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  definition JSONB DEFAULT '{}',
  created_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE workspace_queries ENABLE ROW LEVEL SECURITY;

  workspace_id IN (SELECT id FROM workspaces WHERE owner_id = auth.uid())
);

CREATE TABLE IF NOT EXISTS workspace_macros (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
