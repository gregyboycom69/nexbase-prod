=== FEATURE 7 - ALIGNMENT AND DISTRIBUTION TOOLS ===

Add alignment toolbar that appears when 2+ controls selected.

To select multiple: Shift+Click each control.

When multiple selected:
Show alignment toolbar above canvas:
[Align Left] [Center H] [Align Right] [Align Top] [Center V] [Align Bottom]
[Distribute H] [Distribute V] [Same Width] [Same Height]

Align Left: set all selected controls x = leftmost x
Center H: center all horizontally around midpoint
Align Right: set all right edges to rightmost right edge
Align Top: set all y = topmost y
Center V: center all vertically
Align Bottom: align bottom edges
Distribute H: equal horizontal spacing between controls
Distribute V: equal vertical spacing between controls
Same Width: set all to width of first selected
Same Height: set all to height of first selected

=== FEATURE 8 - UNDO/REDO HISTORY ===

Keep history of last 30 canvas states.

When any change is made (add/delete/move/resize/property change):
Push snapshot of current controls array to history stack.

Ctrl+Z: pop from history, restore previous state
Ctrl+Y: redo (pop from redo stack)

Show undo/redo buttons in toolbar:
[↩ Undo] [↪ Redo]
Disabled (grayed) when nothing to undo/redo.
Tooltip shows what will be undone: "Undo: Move Label"
