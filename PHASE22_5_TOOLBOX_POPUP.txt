FIX 22.5.1 - TOOLBOX SCROLLING
═══════════════════════════════════════════════════════════════════

PROBLEM:
The toolbox panel on left side of form designer contains:
- BASIC group: Select, Label, Heading, TextBox, Button
- INPUTS group: ComboBox, CheckBox, DatePicker, NumberBox
- More groups below (LAYOUT, ADVANCED, etc.)

User can see only the top items. Cannot scroll to reach 
controls below. Toolbox does not have working overflow scroll.

INVESTIGATE:
src/app/(app)/studio/[slug]/page.tsx

Find the container that renders the toolbox. It uses CONTROL_TYPES 
array. Look for the parent div that wraps these controls.

The container probably looks like:
<div style={{ width: 80, background: '#fff', ... }}>
  {CONTROL_TYPES.map(ctrl => (
    <div>{ctrl.name}</div>
  ))}
</div>

FIX:
Add overflow scrolling to the toolbox container:

<div style={{ 
  width: 80, 
  background: '#fff',
  height: '100%',                    // KEY: fixed height
  overflowY: 'auto',                  // KEY: enable scroll
  overflowX: 'hidden',
  scrollbarWidth: 'thin',             // Firefox thin scrollbar
  paddingRight: 2,                    // Space for scrollbar
}}>
  {CONTROL_TYPES.map(...)}
</div>

Make sure parent container does NOT have overflow: hidden 
preventing the scroll.

Also add webkit scrollbar styling for Chrome/Edge:

style={{
  // ... existing
}}
className="toolbox-scroll"

Then in a style tag or global CSS:
.toolbox-scroll::-webkit-scrollbar {
  width: 6px;
}
.toolbox-scroll::-webkit-scrollbar-thumb {
  background: #cbd5e1;
  border-radius: 3px;
}
.toolbox-scroll::-webkit-scrollbar-track {
  background: transparent;
}

TEST:
1. Open form designer
2. Look at toolbox on left
3. Try scrolling inside it
4. See ALL controls (BASIC, INPUTS, LAYOUT, ADVANCED, etc.)

FIX 22.5.2 - POPUP/MODAL FORM RENDERING
═══════════════════════════════════════════════════════════════════

PROBLEM:
When creating a new form, user can select "Popup / Modal" as 
form_type. The option exists in the dropdown:

<option value="popup">Popup / Modal - opens as dialog over another form</option>

BUT when the form is published with form_type='popup', it doesn't 
render as a popup. It just shows as a normal full-page form.

INVESTIGATE:
The form_type is stored in pages table (probably page.form_type 
or page.type or similar column).

Need to check:
- src/app/app/[slug]/page.tsx - published app renderer
- src/app/preview/[slug]/page.tsx - preview renderer

Look at how forms are rendered. Currently probably renders all 
forms as full-page regardless of form_type.

FIX:
Check form_type and render accordingly.

In src/app/app/[slug]/page.tsx, before rendering form content:

const formType = activePage?.form_type || 'single'

if (formType === 'popup' || formType === 'modal') {
  // Render as modal overlay
  return (
    <>
      {/* Background/parent form context */}
      <div style={{
        position: 'fixed',
        inset: 0,
        background: 'rgba(15, 23, 42, 0.5)',
        display: 'flex',
        alignItems: 'center',
        justifyContent: 'center',
        zIndex: 1000,
        padding: 24,
      }}>
        <div style={{
          background: '#ffffff',
          borderRadius: 12,
          padding: 32,
          maxWidth: 600,
          width: '100%',
          maxHeight: '90vh',
          overflowY: 'auto',
          boxShadow: '0 20px 50px rgba(0, 0, 0, 0.25)',
          position: 'relative',
        }}>
          {/* Close button */}
          <button
            onClick={() => {
              // Close popup - go back to previous form/dashboard
              window.history.back()
            }}
            style={{
              position: 'absolute',
              top: 16,
              right: 16,
              background: 'transparent',
              border: 'none',
              fontSize: 24,
              cursor: 'pointer',
              color: '#64748b',
            }}
          >
            ×
          </button>
          
          {/* Form content */}
          {renderFormContent()}
        </div>
      </div>
    </>
  )
}

// Otherwise render normally
return renderFormContent()

Apply SAME logic in:
- src/app/preview/[slug]/page.tsx
- src/app/(app)/studio/[slug]/page.tsx (Form View mode)
