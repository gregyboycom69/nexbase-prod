=== TASK 2 - RENDER CONTROLS IN PUBLISHED MODE ===

In published mode controls are INTERACTIVE not just visual:

TextBox:
  Renders as real <input> with the placeholder
  Saves value to local form state using fieldKey as the key
  Styled with the control radius, fontSize, bg, color from props
  On focus shows indigo border glow

ComboBox:
  Renders as real <select>
  Options come from props.options split by comma
  Saves selected value to form state using fieldKey

CheckBox:
  Renders as real clickable checkbox
  Saves true/false to form state using fieldKey

DatePicker:
  Renders as <input type="date">
  Saves to form state using fieldKey

NumberBox:
  Renders as <input type="number">
  Saves to form state using fieldKey

Button:
  Renders as clickable button with hover and active states
  When clicked runs the macro steps from control.macro_steps
  Shows loading spinner while macro runs

DataTable:
  Renders a real interactive table
  Loads data from Supabase app_data table filtered by workspace_id and table_name (from props.sourceTable)
  Shows columns from props.columns
  Has search input at top if props.showSearch is true
  Has Export CSV button if props.showExport is true
  Has Add Row button if props.allowAdd is true
  Clicking a row selects it and fills any connected form fields
  Has pagination at bottom

DataGrid:
  Same as DataTable but in MS Access datasheet style
  Editable cells - click to edit inline
  Tab key moves to next cell
  Enter key saves the row

Modal:
  Normally hidden
  Becomes visible when a Button with action "showModal" targets this control id
  Shows as overlay with the modal content
  Close button hides it

TabPanel:
  Shows clickable tabs
  Clicking tab switches content
  Each tab content area can have its own controls (from props.tabContent)

Chart:
  Loads data from app_data table
  Renders using simple CSS bars (no library needed)
  Bar chart: show bars proportional to values
  Line chart: show connected dots
  Pie: show colored segments

ProgressBar:
  Shows progress from props.value (0-100)
  Animated fill

NavigationButtons:
  Connected to a DataTable or DataGrid on the same page
  First, Prev, Next, Last buttons navigate through records
  Shows current record number

=== TASK 3 - MACRO ENGINE IN PUBLISHED APP ===

When a Button is clicked in the published app, run its macro_steps array.

Create src/lib/macroEngine.ts with a runMacro function:

async function runMacro(steps, context) {
  context has: formData, setFormData, workspaceId, navigate, showToast, showModal, hideModal, supabase
  
  for each step in steps:
  
  if action === 'save':
    Insert into app_data table:
    { workspace_id: workspaceId, table_name: vals.table, data: formData }
    Show success toast after save

  if action === 'newrec':
    Clear all form fields (setFormData({}))

  if action === 'delrec':
    Show confirm dialog
    If confirmed: delete from app_data where id = formData.id

  if action === 'goto':
    Navigate to the page with slug = vals.page

  if action === 'toast':
    Show toast notification with vals.msg and vals.type (success/error/warning/info)

  if action === 'alert':
    window.alert(vals.msg)

  if action === 'confirm':
    result = window.confirm(vals.msg)
    If result is false: stop running macro

  if action === 'filter':
    Set filter on the DataTable with fieldKey = vals.field, value = vals.val

  if action === 'clearfil':
    Clear all filters on DataTable

  if action === 'expcsv':
    Fetch all rows from app_data where table_name = vals.table
    Convert to CSV and download as vals.fname + .csv

  if action === 'setval':
    setFormData(prev => ({...prev, [vals.field]: vals.val}))

  if action === 'calc':
    Evaluate vals.formula replacing field names with formData values
    Store result in vals.target field

  if action === 'auditlog':
    Insert into audit_log table: { workspace_id, action: vals.action, record_name: formData.name or formData.id }

  if action === 'showModal':
    Call showModal(vals.modalId) to show a Modal control

  if action === 'hideModal':
    Call hideModal() to hide current modal

  if action === 'print':
    window.print()

  if action === 'mailto':
    Open mailto link with formData values
