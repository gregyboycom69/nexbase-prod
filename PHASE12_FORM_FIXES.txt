=== ISSUE 4 - FORM VIEW / PREVIEW ===

The Form View button must show an interactive preview of the form.

When Form View is clicked:
1. Hide toolbox and property sheet
2. Canvas takes full width
3. All controls become interactive:

TextBox → <input type="text" className="p-inp"> 
  value comes from formData[ctrl.props.controlSource] or formData[ctrl.id]
  onChange updates formData state

ComboBox → <select className="p-sel">
  options from ctrl.props.options (comma split) 
  OR if Row Source = table: load from app_data
  onChange updates formData

CheckBox → real clickable checkbox
  checked = formData[ctrl.props.controlSource]

DatePicker → <input type="date">
  value from formData

NumberBox → <input type="number">
  value from formData

Button → clickable button with hover effect
  onClick runs ctrl.props.steps (macro steps)

Label and Heading → static text (not interactive)

If form has Record Source:
- On load: fetch records from app_data WHERE workspace_id AND table_name = recordSource
- Populate bound controls with first record values
- Show navigation bar at bottom of form:

NAVIGATION BAR:
|◀| |◀| Record [_1_] of [47] |▶| |▶|  [+ New]  🔍[search input]

Navigation bar behavior:
- |◀| First: go to record index 0
- |◀| Prev: go to previous record
- Number input: type number, jump to that record
- |▶| Next: go to next record  
- |▶| Last: go to last record
- + New: clear formData for new record entry
- Search: filter records by typing (searches all text fields)

When navigating: update all bound controls with new record values.

SAVE in form view:
When Button with action "save" is clicked:
Collect all formData values.
If current record has id: UPDATE app_data SET data = formData WHERE id = recordId
If new record: INSERT into app_data: { workspace_id, table_name: recordSource, data: formData }
Show success toast.
