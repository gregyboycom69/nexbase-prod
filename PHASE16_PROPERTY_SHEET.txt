The PropertySheet receives these props:
- selectedControl: the currently selected control object (or null)
- formPage: the current form/page object (has record_source etc)
- tableFields: array of fields from the bound table
- workspaceMacros: array of macros from workspace_macros table
- workspaceTables: array of all tables in this workspace
- workspaceQueries: array of all queries
- workspaceForms: array of all forms/pages
- onUpdateControl: function(controlId, changes) - updates control
- onUpdateForm: function(changes) - updates form/page properties

=== HOW TO CONNECT EVERYTHING ===

In the studio page (page.tsx), maintain these states:
- tableFields: array - fields from current form's record source table
- workspaceMacros: array - all macros from workspace_macros
- workspaceTables: array - all tables from workspace_tables
- workspaceQueries: array - all queries from workspace_queries
- workspaceForms: array - all pages/forms for this workspace

Load on studio mount:
const { data: macros } = await supabase
  .from('workspace_macros')
  .select('*')
  .eq('workspace_id', workspaceId)
setWorkspaceMacros(macros || [])

const { data: tables } = await supabase
  .from('workspace_tables')
  .select('*')
  .eq('workspace_id', workspaceId)
setWorkspaceTables(tables || [])

When form's record_source changes:
const table = workspaceTables.find(t => t.name === newRecordSource)
if (table) setTableFields(table.fields || [])

Pass all these to PropertySheet component.
