=== TASK 3 - ADD QUERY BUILDER PAGE TO STUDIO ===

Add a "Queries" tab to the studio top navigation (next to the workspace name).
When clicked it shows a Query Builder panel instead of the canvas.

The Query Builder has:
- Left panel (200px): Table selector
  - Title "Tables"
  - List of table names from props (default: Customers, Orders, Products)
  - Click a table to add it to the query
  - Added tables show as cards with their columns listed

- Center panel: QBE Grid (Query By Example - exactly like MS Access)
  - Grid with columns: Field, Table, Sort, Show, Criteria, Or
  - User can add fields by clicking + 
  - Each row is one field in the query
  - Sort column has dropdown: None, Ascending, Descending
  - Show column has checkbox
  - Criteria column is a text input
  - Can add multiple criteria rows

- Right panel (200px): Query Properties
  - Query Name input
  - Query Type: Select, Insert, Update, Delete
  - Top N records input
  - Unique values checkbox

- Bottom: Run Query button (indigo), Save Query button, Clear button
