FIX 22.1 - LABEL COLOR IN DESIGN VIEW
═══════════════════════════════════════════════════════════════════

PROBLEM:
When user sets color on a Label control via Property Sheet,
the change DOES save, but it doesn't show in Design View.
Only shows after switching to Form View.

INVESTIGATE:
src/app/(app)/studio/[slug]/page.tsx or 
src/components/controls/CtrlRender.tsx

Find where Label is rendered in Design View vs Form View.
Look for: if (ctrl.type === 'Label')

The Design View rendering probably ignores ctrl.props.color or 
uses a hardcoded color.

FIX:
Ensure Design View renders Label with the SAME styling as 
Form View:

if (ctrl.type === 'Label') {
  return (
    <span style={{
      color: ctrl.props?.color || '#374151',
      fontSize: ctrl.props?.fontSize || 14,
      fontWeight: ctrl.props?.bold ? 700 : 400,
      fontStyle: ctrl.props?.italic ? 'italic' : 'normal',
      textDecoration: ctrl.props?.underline ? 'underline' : 'none',
    }}>
      {ctrl.props?.text || ctrl.props?.caption || 'Label'}
    </span>
  )
}

Make sure this rendering is identical in BOTH Design View 
and Form View. Currently they likely differ.

PROBLEM:

via fontStyle. Apply this to:

- Heading

- Any other text control

Make sure Italic property exists in Property Sheet for all 
these controls.

FIX 22.4 - TOOLBOX SCROLLING
═══════════════════════════════════════════════════════════════════

PROBLEM:
The toolbox (left panel) in form designer shows controls like:
Select, Label, Heading, TextBox, Button, ComboBox, CheckBox, 
DatePicker, NumberBox, etc.

The toolbox panel has fixed height and CANNOT scroll.
User cannot access controls that are below the visible area.

INVESTIGATE:
Find the toolbox component in:
src/app/(app)/studio/[slug]/page.tsx
Or src/components/Toolbox.tsx (if separate component)

Look for the container div that holds all controls.
It probably has:
- Fixed height
- overflow: hidden (or no overflow set)

FIX:
Make the toolbox scrollable:

<div style={{
  // existing styles
  overflowY: 'auto',           // Add vertical scroll
  maxHeight: 'calc(100vh - 200px)',  // Adjust height
  // OR
  height: '100%',
  paddingRight: 4,              // Space for scrollbar
}}>
  {/* Toolbox controls */}
</div>

Make sure scroll only appears when content overflows (not always).

Add scrollbar styling for clean look:

style={{
  overflowY: 'auto',
  scrollbarWidth: 'thin',
  scrollbarColor: '#cbd5e1 transparent',
}}

And/or via CSS:
.toolbox::-webkit-scrollbar {
  width: 6px;
}
.toolbox::-webkit-scrollbar-thumb {
  background: #cbd5e1;
  border-radius: 3px;
}
.toolbox::-webkit-scrollbar-track {
  background: transparent;
}
