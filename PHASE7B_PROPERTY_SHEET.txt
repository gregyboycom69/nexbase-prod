=== UNDERSTAND THE CONCEPT FIRST ===

In MS Access:
- FORM has "Record Source" property = which table/query it reads from
- TEXTBOX has "Control Source" property = which field from that table
- When user navigates records, ALL bound controls update automatically
- This is called a BOUND FORM

In NexBase:
- PAGE (form) needs "recordSource" = workspace table name
- CONTROL needs "controlSource" = field name from that table
- When form loads it fetches records from Supabase app_data
- Navigation buttons move between records
- All bound controls show the current record's field values

=== TASK 5 - CONTROL SOURCE BINDING IN PREVIEW/PUBLISHED MODE ===

When form is in Preview or Published mode:

ON LOAD:
1. Check page.recordSource (which table this form is bound to)
2. Fetch first record from app_data where table_name = recordSource
3. Store all records in recordset state array
4. Set currentIndex = 0
5. For each bound control (controlSource is set):
   - Set control value = recordset[currentIndex][controlSource]

ON NAVIGATION:
1. currentIndex changes
2. For each bound control:
   - Update displayed value = recordset[currentIndex][controlSource]

ON SAVE BUTTON (macro action = save):
1. Collect all bound control values: { fieldName: value }
2. If currentRecord has id: UPDATE that record in app_data
3. If new record: INSERT into app_data

ON DELETE BUTTON (macro action = delrec):
1. Show confirm dialog
2. DELETE from app_data where id = currentRecord.id
3. Move to next record

=== SQL TO RUN IN SUPABASE FIRST ===

ALTER TABLE pages ADD COLUMN IF NOT EXISTS record_source TEXT;
ALTER TABLE pages ADD COLUMN IF NOT EXISTS form_filter TEXT;
ALTER TABLE pages ADD COLUMN IF NOT EXISTS order_by TEXT;
ALTER TABLE pages ADD COLUMN IF NOT EXISTS allow_edits BOOLEAN DEFAULT true;
ALTER TABLE pages ADD COLUMN IF NOT EXISTS allow_additions BOOLEAN DEFAULT true;
ALTER TABLE pages ADD COLUMN IF NOT EXISTS allow_deletions BOOLEAN DEFAULT true;
ALTER TABLE pages ADD COLUMN IF NOT EXISTS navigation_buttons BOOLEAN DEFAULT true;
ALTER TABLE pages ADD COLUMN IF NOT EXISTS default_view TEXT DEFAULT 'single';
ALTER TABLE pages ADD COLUMN IF NOT EXISTS on_open_macro TEXT;
ALTER TABLE pages ADD COLUMN IF NOT EXISTS on_load_macro TEXT;
ALTER TABLE pages ADD COLUMN IF NOT EXISTS on_close_macro TEXT;

CREATE TABLE IF NOT EXISTS workspace_tables (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id UUID REFERENCES workspaces(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  slug TEXT NOT NULL,
  fields JSONB DEFAULT '[]',
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(workspace_id, slug)
);
ALTER TABLE workspace_tables ENABLE ROW LEVEL SECURITY;
CREATE POLICY owner_wt ON workspace_tables FOR ALL USING (
  workspace_id IN (SELECT id FROM workspaces WHERE owner_id = auth.uid())
);
