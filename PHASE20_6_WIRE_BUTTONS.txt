FIX 20.6.1 - SAVE BUTTON STANDARD ACTION
═══════════════════════════════════════════════════════════════════

When user clicks Save button in form:
1. Collect all bound field values from form
2. Insert into app_data table for that form's bound table
3. Show success/error feedback
4. Update internal currentRecordId for subsequent edits

FILE: Wherever the form renders buttons (likely Form runtime 
component). The button control needs to know it's a Save action.

Approach: Add a "buttonAction" prop to Button controls.
Standard values: 'save', 'new', 'delete', 'next', 'previous'

When auto-generating NavigationButtons, set actions:
- First button: { type: 'Button', props: { label: 'Save', buttonAction: 'save' }}
- Second button: { type: 'Button', props: { label: 'New', buttonAction: 'new' }}
- Third button: { type: 'Button', props: { label: 'Delete', buttonAction: 'delete' }}

In form runtime, button onClick checks buttonAction:

const handleButtonClick = async (ctrl) => {
  const action = ctrl.props?.buttonAction
  
  if (action === 'save') {
    await handleSaveAction()
  } else if (action === 'new') {
    handleNewAction()
  } else if (action === 'delete') {
    await handleDeleteAction()
  } else if (action === 'next') {
    handleNextRecord()
  } else if (action === 'previous') {
    handlePreviousRecord()
  }
}

FIX 20.6.2 - SAVE ACTION IMPLEMENTATION
═══════════════════════════════════════════════════════════════════

const handleSaveAction = async () => {
  // Get form's bound table (form name should match table name 
  // for auto-generated forms)
  const tableName = activePage?.name || formName
  
  // Validate required fields
  const requiredFields = fields.filter(f => 
    f.required && f.type !== 'AutoNumber' && f.name !== 'id'
  )
  for (const field of requiredFields) {
    if (!formValues[field.name]) {
      alert(`${field.caption || field.name} is required`)
      return
    }
  }
  
  if (currentRecordId) {
    // Update existing record
    const { error } = await supabase
      .from('app_data')
      .update({ data: formValues })
      .eq('id', currentRecordId)
    
    if (error) {
      alert('Save failed: ' + error.message)
    } else {
      // Brief visual feedback
      setSaveFeedback('Saved!')
      setTimeout(() => setSaveFeedback(null), 2000)
    }
  } else {
    // Insert new record
    const { data, error } = await supabase
      .from('app_data')
      .insert({
        workspace_id: workspaceId,
        table_name: tableName,
        data: formValues,
      })
      .select('id')
      .single()
    
    if (error) {
      alert('Save failed: ' + error.message)
    } else {
      setCurrentRecordId(data.id)
      setSaveFeedback('Saved!')
      setTimeout(() => setSaveFeedback(null), 2000)
    }
  }
}

const handleNewAction = () => {
  // Confirm if unsaved changes
  if (Object.keys(formValues).length > 0 && !currentRecordId) {
    if (!confirm('Discard unsaved changes?')) return
  }
  
  // Clear form
  setFormValues({})
  setCurrentRecordId(null)
  setSaveFeedback('New record')
  setTimeout(() => setSaveFeedback(null), 2000)
}

FIX 20.6.4 - DELETE ACTION IMPLEMENTATION
═══════════════════════════════════════════════════════════════════

const handleDeleteAction = async () => {
  if (!currentRecordId) {
    alert('No record loaded. Save first or load existing record.')
    return
  }
  
  if (!confirm('Delete this record? This cannot be undone.')) return
  
  const { error } = await supabase
    .from('app_data')
    .delete()
    .eq('id', currentRecordId)
  
  if (error) {
    alert('Delete failed: ' + error.message)
  } else {
    setFormValues({})
    setCurrentRecordId(null)
    setSaveFeedback('Deleted')
    setTimeout(() => setSaveFeedback(null), 2000)
  }
}

FIX 20.6.5 - FIELD INPUT BINDING
═══════════════════════════════════════════════════════════════════

Make sure form input controls update formValues state.

For each TextBox/NumberBox/DatePicker etc. that binds to a field:

<input
  value={formValues[ctrl.props?.fieldName] || ''}
  onChange={e => setFormValues({
    ...formValues,
    [ctrl.props?.fieldName]: e.target.value
  })}
  type={getInputType(ctrl.props?.fieldType)}
  placeholder={ctrl.props?.placeholder || ''}
/>

Helper function:
const getInputType = (fieldType: string) => {
  switch (fieldType) {
    case 'Number':
    case 'Currency':
      return 'number'
    case 'Date/Time':
      return 'date'
    case 'Email':
      return 'email'
    case 'Phone':
      return 'tel'
    case 'URL':
      return 'url'
    default:
      return 'text'
  }
}
