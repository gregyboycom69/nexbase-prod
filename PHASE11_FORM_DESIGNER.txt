Controls are placed by absolute position within their section.
Each control stores which section it belongs to (header/detail/footer).

=== DRAG AND DRAW ===

Same working drag-draw from the previous canvas:

1. Click tool in toolbox → sets activeTool
2. Mouse down on canvas → start drawing ghost rect
3. Mouse move → update ghost rect (dashed indigo border)
4. Mouse up → create control at that position and size

Use useRef for isDrawing, drawStart.
Use window.addEventListener for mousemove and mouseup.
Ghost rect shows while drawing.
Control created on mouseup if size > 10px.

For moving: mousedown on control body → drag to new position.
For resizing: 8 handles on selected control → drag to resize.

Controls store x, y, w, h and section (header/detail/footer).
x and y are relative to their section top.

=== FORM VIEW (Preview) ===

Design/Form View/Datasheet toggle buttons in toolbar.

When Form View clicked:
- Hide toolbox
- Hide property sheet
- Show form taking full width
- Controls become interactive:
  TextBox → real <input>
  ComboBox → real <select>
  CheckBox → clickable
  DatePicker → <input type="date">
  NumberBox → <input type="number">
  Button → clickable, runs macro steps

If form has Record Source:
- Load records from app_data WHERE workspace_id AND table_name = recordSource
- Show first record data in bound controls (controlSource fields)
- Show navigation bar at bottom:
  |◀ ◀ Record [1] of [5] ▶ ▶| + New | 🔍 Search

Navigation:
- First/Prev/Next/Last buttons move through records
- Bound controls update to show current record values
- + New clears form for new record entry

When Save macro runs (button with save action):
Collect all bound control values by fieldKey/controlSource.
INSERT or UPDATE record in app_data.

Design button switches back to design view.

=== SAVING ===

Auto-save: any control change → debounce 800ms → save to Supabase controls table.
Show "Saving..." indicator in toolbar, then "Saved ✓".

Manual save: Ctrl+S or Save button.

Save each control as:
{
  id, page_id,
  type, x, y, w, h,
  section: "header" | "detail" | "footer",
  props: { caption, color, bg, radius, fontSize, fieldKey, 
           controlSource, placeholder, options, steps, ... all other props }
}

Save form properties back to pages table:
record_source, allow_edits, allow_additions, allow_deletions, navigation_buttons

=== SUPABASE ===

On studio load:
1. GET workspace by slug
2. GET all pages for this workspace
3. GET all workspace_tables
4. GET all workspace_queries  
5. GET all workspace_macros
6. Load first page controls from controls table

When form Record Source changes:
GET workspace_tables entry for that table
Store fields array in local state for Control Source dropdowns

When control saved:
UPSERT controls table

=== SQL TO RUN IN SUPABASE ===

ALTER TABLE pages ADD COLUMN IF NOT EXISTS record_source TEXT;
ALTER TABLE pages ADD COLUMN IF NOT EXISTS allow_edits BOOLEAN DEFAULT true;
ALTER TABLE pages ADD COLUMN IF NOT EXISTS allow_additions BOOLEAN DEFAULT true;
ALTER TABLE pages ADD COLUMN IF NOT EXISTS allow_deletions BOOLEAN DEFAULT true;
ALTER TABLE pages ADD COLUMN IF NOT EXISTS navigation_buttons BOOLEAN DEFAULT true;
ALTER TABLE controls ADD COLUMN IF NOT EXISTS section TEXT DEFAULT 'detail';
