FIX 19.1 - PROPERTY SHEET TYPING LAG
────────────────────────────────────────────────────────────────────

PROBLEM:
Typing in property sheet inputs is laggy. Each keystroke
triggers a Supabase save, which causes characters to be lost
or delayed when typing.

FILE: src/app/(app)/studio/[slug]/page.tsx
(also check src/components/PropertySheet.tsx if it exists)

SOLUTION:
Change ALL text inputs and textareas in Property Sheet to
save on BLUR only, not on every change.

For EACH text input/textarea in Property Sheet:

CURRENT (BROKEN):
<input
  value={ctrl.props?.label || ''}
  onChange={e => updateCtrlProp('label', e.target.value)}
/>

CHANGE TO:
<input
  defaultValue={ctrl.props?.label || ''}
  onBlur={e => {
    if (e.target.value !== ctrl.props?.label) {
      updateCtrlProp('label', e.target.value);
    }
  }}
  key={`${ctrl.id}-label`}
/>

KEY POINTS:
- Use defaultValue (not value) for uncontrolled input
- Use onBlur (not onChange) so save happens on click-away
- Add unique key prop to force re-render when control changes
- Only save if value actually changed (prevents redundant saves)

For dropdowns and select elements, KEEP onChange
(they don't have typing lag).

For checkboxes and toggles, KEEP onChange.

TEST CRITERIA:
- Type "Customer Full Name" continuously without lag
- Click somewhere else → input value is saved
- Click on different control → previous value still saved
- No visible delay between keystrokes

const BAD_COLORS = [
  '#7f1d1d', '#991b1b', '#450a0a', '#1f1d1d',
  '#2d1d1d', '#3d1d1d', '#181818', '#000000'
].map(c => c.toLowerCase());

const isBadColor = (color) => {
  if (!color) return false;
  return BAD_COLORS.includes(color.toLowerCase());
};

const getControlDefaultBg = (type) => {
  const defaults = {
    TextBox: theme.controls.textBoxBg,
    Label: 'transparent',
    Heading: 'transparent',
    Button: theme.controls.buttonBg,
    ComboBox: theme.controls.comboBg,
    CheckBox: 'transparent',
    DatePicker: theme.controls.textBoxBg,
    NumberBox: theme.controls.textBoxBg,
    Badge: theme.controls.badgeBg,
    Card: theme.controls.cardBg,
    Divider: theme.controls.dividerColor,
  };
  return defaults[type] || theme.bg.card;
};

const getControlDefaultColor = (type) => {
  const defaults = {
    TextBox: theme.controls.textBoxText,
    Label: theme.controls.labelText,
    Heading: theme.controls.headingText,
    Button: theme.controls.buttonText,
    ComboBox: theme.controls.comboText,
    CheckBox: theme.controls.checkboxText,
    DatePicker: theme.controls.textBoxText,
    NumberBox: theme.controls.textBoxText,
    Badge: theme.controls.badgeText,
    Card: theme.controls.cardText,
  };
  return defaults[type] || theme.text.primary;
};

const sanitizeControl = (ctrl) => {
  const sanitized = { ...ctrl, props: { ...ctrl.props } };

  if (isBadColor(sanitized.props?.bg)) {
    sanitized.props.bg = getControlDefaultBg(ctrl.type);
  }
  if (isBadColor(sanitized.props?.color)) {
    sanitized.props.color = getControlDefaultColor(ctrl.type);
  }

  return sanitized;
};

MACRO ENGINE FUNCTION:
const runMacro = async (button, allControls) => {
  if (!button.props?.macroSteps) return;

  for (const step of button.props.macroSteps) {
    if (step.action === 'save') {
      // Collect form data from controls with controlSource
      const dataToSave = {};
      allControls.forEach(ctrl => {
        const source = ctrl.props?.controlSource;
        if (source) {
          dataToSave[source] = formData[ctrl.id] ?? null;
        }
      });

      const { error } = await supabase
        .from('app_data')
        .insert({
          workspace_id: workspaceId,
          table_name: activePage.record_source,
          data: dataToSave,
          created_at: new Date().toISOString()
        });

      if (error) {
        alert('Save failed: ' + error.message);
        return;
      }
      alert('Saved!');
    }

    if (step.action === 'goto') {
      const targetPage = pages.find(p => p.name === step.target || p.slug === step.target);
      if (targetPage) {
        setActivePageId(targetPage.id);
      }
    }

    if (step.action === 'toast') {
      alert(step.message || 'Done');
    }

    if (step.action === 'newrec') {
      setFormData({});
    }
  }
};

WHEN BUTTON CLICKED IN FORM VIEW:
