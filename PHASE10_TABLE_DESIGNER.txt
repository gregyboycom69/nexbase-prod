=== LAYOUT ===

src/app/(app)/studio/[slug]/tables/page.tsx

Split layout:
LEFT (220px): List of all tables in this workspace
RIGHT: Table designer (field grid on top, field properties on bottom)

=== LEFT PANEL ===

Title: "Tables"
Lists all tables from workspace_tables Supabase table.
Each table row: grid icon + table name.
Click to select and load in right panel.
Selected table highlighted indigo.
Right-click menu: Rename | Delete.
Bottom: "+ New Table" button.
Clicking New Table: shows inline text input in the list, press Enter to create.
New table saved to workspace_tables with default id field.

=== RIGHT PANEL - TOP HALF (Field Grid) ===

When table selected shows a grid with 3 columns:
Column 1 (30px): Primary key icon (🔑) for primary key fields
Column 2 (200px): Field Name - text input
Column 3 (160px): Data Type - dropdown select
Column 4 (flex): Description - text input

First row always: 🔑 | id | AutoNumber | Primary Key (locked, cannot delete)

Each additional row is one field.
Clicking a row selects it (highlights blue) and shows its properties in bottom panel.
Delete key on selected row: confirm then remove.
Tab between cells.
Bottom of grid: "+ Add Field" row that adds new empty field when clicked.

Data Type dropdown options:
Short Text | Long Text | Number | Currency | AutoNumber | Date/Time | Yes/No | Email | Phone | URL | Choice | Lookup

When Choice selected: show extra input below for "Options (comma separated)"
When Lookup selected: show extra dropdown "Related Table" from workspace tables list

Toolbar above grid:
[Table name - editable input] [Save Table] [Design View] [Datasheet View]

=== SUPABASE OPERATIONS ===

On page load:
GET all workspace_tables WHERE workspace_id = current workspace id
Populate left panel list.

On table click:
GET workspace_tables by id
Parse fields JSONB array
Populate field grid.

On Save Table:
UPSERT workspace_tables:
  id (if existing) or new UUID
  workspace_id
  name: tableName
  slug: tableName.toLowerCase().replace(/ /g, '_')
  fields: JSON.stringify(fieldsArray)

Each field in array:
{
  name, type, description, required, defaultValue,
  validationRule, validationText, caption,
  size, format, decimalPlaces, allowZeroLength, indexed,
  options (for Choice), relatedTable, relatedField (for Lookup),
  isPrimaryKey
}

On Delete Table:
DELETE from workspace_tables WHERE id = tableId
Confirm before deleting.

On New Table:
INSERT workspace_tables with name and default fields:
[{ name: "id", type: "AutoNumber", isPrimaryKey: true, required: true }]

=== DATASHEET VIEW ===

When Datasheet View button clicked:
Switch right panel to show a spreadsheet grid.
Fetch records from app_data WHERE workspace_id AND table_name = current table slug.
Show column headers from field definitions.
Show all records as rows.
Last row shows * for new record entry.
Click cell to edit inline.
Clicking * row: creates new empty record.
Save edits: UPSERT into app_data.
Right-click row: Delete Record option.
Toolbar shows: New | Save | Delete | Refresh | Filter | Sort

If no records: show empty grid with just the * new row.
