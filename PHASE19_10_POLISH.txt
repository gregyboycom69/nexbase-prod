FIX 19.10.1 - SANITIZE EXISTING DATA IN SUPABASE
═══════════════════════════════════════════════════════════════════

PROBLEM: 
The sanitizeControl function added in Phase 19.6 only fixes 
colors at RENDER time. But existing pages in Supabase still 
have bg:#7f1d1d in their controls JSON.

We need a one-time data migration to clean existing data.

SOLUTION A - Server-side migration script:

Create file: scripts/sanitize-control-colors.ts

import { createClient } from '@supabase/supabase-js'

const supabase = createClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.SUPABASE_SERVICE_ROLE_KEY!
)

const BAD_COLORS = [
  '#7f1d1d', '#991b1b', '#450a0a', '#1f1d1d',
  '#2d1d1d', '#3d1d1d', '#181818', '#000000'
]

const DEFAULT_BG = {
  TextBox: '#ffffff',
  NumberBox: '#ffffff',
  DatePicker: '#ffffff',
  ComboBox: '#ffffff',
  Button: '#4f46e5',
  Label: 'transparent',
  Heading: 'transparent',
  CheckBox: 'transparent',
  Card: '#ffffff',
}

const DEFAULT_COLOR = {
  TextBox: '#1e293b',
  NumberBox: '#1e293b',
  DatePicker: '#1e293b',
  ComboBox: '#374151',
  Button: '#ffffff',
  Label: '#374151',
  Heading: '#0f172a',
  CheckBox: '#374151',
  Card: '#0f172a',
}

async function sanitize() {
  const { data: pages, error } = await supabase
    .from('pages')
    .select('id, controls')
  
  if (error) {
    console.error(error)
    return
  }
  
  let fixedCount = 0
  
  for (const page of pages) {
    if (!page.controls || !Array.isArray(page.controls)) continue
    
    let modified = false
    const newControls = page.controls.map(ctrl => {
      const newProps = { ...(ctrl.props || {}) }
      
      if (BAD_COLORS.includes((newProps.bg || '').toLowerCase())) {
        newProps.bg = DEFAULT_BG[ctrl.type] || '#ffffff'
        modified = true
      }
      
      if (BAD_COLORS.includes((newProps.color || '').toLowerCase())) {
        newProps.color = DEFAULT_COLOR[ctrl.type] || '#1e293b'
        modified = true
      }
      
      // Fix button contrast - if button has light bg, use dark text
      if (ctrl.type === 'Button') {
        const bg = newProps.bg || '#4f46e5'
        const isLightBg = isLightColor(bg)
        if (isLightBg && (!newProps.color || newProps.color === '#ffffff')) {
          newProps.color = '#1e293b'
          modified = true
        }
      }
      
      return modified ? { ...ctrl, props: newProps } : ctrl
    })
    
    if (modified) {
      const { error: updateError } = await supabase
        .from('pages')
        .update({ controls: newControls })
        .eq('id', page.id)
      
      if (!updateError) {
        fixedCount++
        console.log('Fixed page', page.id)
      }
    }
  }
  
  console.log('Total pages fixed:', fixedCount)
}

function isLightColor(hex) {
  const c = hex.replace('#', '')
  const r = parseInt(c.substr(0, 2), 16)
  const g = parseInt(c.substr(2, 2), 16)
  const b = parseInt(c.substr(4, 2), 16)
  const brightness = (r * 299 + g * 587 + b * 114) / 1000
  return brightness > 155
}

sanitize()

RUN ONCE:
npx tsx scripts/sanitize-control-colors.ts

This cleans all existing pages in Supabase one time.

FIX 19.10.4 - BUTTON CONTRAST AUTO-CALCULATION
═══════════════════════════════════════════════════════════════════

PROBLEM:
When user picks a light background color for a button,
text stays white and becomes unreadable.

FILE: src/app/(app)/studio/[slug]/page.tsx
(or wherever Button is rendered)

ADD function:

function getContrastText(bgHex) {
  if (!bgHex || bgHex === 'transparent') return '#1e293b'
  
  const c = bgHex.replace('#', '')
  if (c.length !== 6) return '#ffffff'
  
  const r = parseInt(c.substr(0, 2), 16)
  const g = parseInt(c.substr(2, 2), 16)
  const b = parseInt(c.substr(4, 2), 16)
  const brightness = (r * 299 + g * 587 + b * 114) / 1000
  
  return brightness > 155 ? '#1e293b' : '#ffffff'
}

USE in Button render:

{ctrl.type === 'Button' && (
  <button style={{
    background: ctrl.props?.bg || '#4f46e5',
    color: ctrl.props?.color || getContrastText(ctrl.props?.bg || '#4f46e5'),
    // ... other styles
  }}>
    {ctrl.props?.label || 'Button'}
  </button>
)}

This ensures readable text regardless of bg color.
