=== FIX 4 - PROPERTY SHEET FULLY WORKING ===

The property sheet must show and save ALL properties.

When TextBox selected - DATA tab MUST show:
Control Source dropdown populated with fields from form's record source table.

Steps to make this work:
1. When studio loads, fetch ALL workspace_tables:
   const {data: wTables} = await supabase
     .from('workspace_tables')
     .select('*')
     .eq('workspace_id', workspaceId)

2. When active page changes, get its record_source:
   const recordSource = activePage?.record_source
   
3. Find the table matching that name:
   const boundTable = wTables?.find(t => t.name === recordSource)
   const tableFields = boundTable?.fields || []

4. Pass tableFields to PropertySheet component

5. In PropertySheet DATA tab for TextBox:
   <select 
     value={ctrl.props?.controlSource || ''}
     onChange={e => updateCtrlProp('controlSource', e.target.value)}
   >
     <option value="">(none)</option>
     {tableFields.map(f => (
       <option key={f.name} value={f.name}>
         {f.caption || f.name}
       </option>
     ))}
   </select>

When FORM is selected (no control) - DATA tab shows:
   <select
     value={activePage?.record_source || ''}
     onChange={async e => {
       await supabase
         .from('pages')
         .update({ record_source: e.target.value })
         .eq('id', activePage.id)
       setActivePage({...activePage, record_source: e.target.value})
     }}
   >
     <option value="">(none)</option>
     {wTables?.map(t => (
       <option key={t.name} value={t.name}>{t.name}</option>
     ))}
   </select>
